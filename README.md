# Cognifyz Technologies – Web Development Internship

## Level 1: HTML, CSS and JavaScript

### Project Title

Interactive Personal Portfolio Website

### Project Overview

This project was developed as part of the Cognifyz Technologies Web Development Internship – Level 1.

The objective is to develop a responsive and interactive personal portfolio website using HTML, CSS and JavaScript.

The website combines basic web development concepts with interactive JavaScript functionality to create an engaging user experience.

### Technologies Used

* HTML5 – Website structure
* CSS3 – Styling and responsive design
* JavaScript – Interactive functionality
* Visual Studio Code – Development environment
* Live Server – Local website hosting

## Task 1: HTML and CSS

### 1. Personal Website

Created a personal portfolio webpage containing:

* Navigation menu with Home, About, JavaScript and Contact links.
* Heading and introductory paragraph.
* Web development image.
* About Me section.
* Contact form with an input field and submit button.

### 2. CSS Styling

Implemented:

* Dark navy and purple color theme.
* Gradient backgrounds.
* Responsive layouts.
* Hover effects and transitions.
* Styled buttons, cards and input fields.

## Task 2: JavaScript

### 1. Color Changing Button

Developed an interactive button that changes its background color whenever the user clicks it.

Concepts used:

* DOM manipulation.
* Event listeners.
* Random color selection.

### 2. Time-Based Greeting Alert

Created a greeting feature that displays messages based on the current system time.

Greeting conditions:

* Before 12 PM – Good Morning.
* 12 PM to before 5 PM – Good Afternoon.
* 5 PM onwards – Good Evening.

Concepts used:

* JavaScript Date object.
* Conditional statements.
* Alert function.

### 3. Addition Calculator

Developed a simple calculator that accepts two numerical inputs and displays their sum.

Features:

* Accepts two numbers.
* Validates empty inputs.
* Converts input values into numbers.
* Calculates and displays the result.

Concepts used:

* DOM manipulation.
* Event listeners.
* Number conversion.
* Arithmetic operations.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html.
5. Right-click and select Open with Live Server.
6. The website will open in your default browser.
